📐 Pricing-Logik

  • €50/Monat verankert €0.10/Nachricht als psychologischen Preis.
  • Top-Ups werden günstiger pro Nachricht (€0.07 → €0.06 → €0.05) → Incentive zum größeren Paket.
  • Keine Affiliate-Provision auf Top-Ups = bessere Margen für dich (Industry-Standard, kommunizier das in den Affiliate-Terms).
  • Average Use ist realistisch ~150-200 msgs/Monat. Nur 5-10% der User schöpfen 500 aus.
  • Bei 1000 zahlenden Subscribers @ avg 200 msgs: ~€28.700/Monat Profit, ~€7.000 API-Kosten.
⚠️ Wichtige Caveats:
  • Diese Kalkulation basiert auf Variant A (frontend-localStorage). Variant B mit echter Quota brauchst du für €-Verkauf — sonst kann User die 500 msgs via Inkognito-Mode umgehen.
  • API-Kosten Sonnet 4.6: €3 in / €15 out per 1M tokens. Wenn Anthropic die Preise senkt → mehr Marge. Aktuelle Preise immer auf Anthropic Console checken.
  • Bei 500+ aktiven Subscribers kann sich ein wechsel zu Haiku 4.5 (€1/€5) lohnen — würde API-Kosten 3x senken bei nur leicht reduzierter Qualität.
