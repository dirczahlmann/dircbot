📐 Pricing-Logik

        
    
          
  • €50/Monat verankert €0.10/Nachricht als psychologischen Preis.
    • 
          
  • Top-Ups werden günstiger pro Nachricht (€0.07 → €0.06 → €0.05) → Incentive zum größeren Paket.
    • 
          
  • Keine Affiliate-Provision auf Top-Ups = bessere Margen für dich (Industry-Standard, kommunizier das in den Affiliate-Terms).

🧪 A/B Prompt-Testing PREVIEW

      
Teste zwei System-Prompt-Varianten gegeneinander. Welcher Style konvertiert besser zu Telegram/Akademie?


      

        

          
Variante A CURRENT

          
Aktueller Prompt: Pattern-Interrupt → 3-Step Framework → Forward-Pull. Strenger Dirc-Voice mit Funnel-Routing zu Telegram (@zahlmann) bei Service-Anfragen + Akademie bei Lernfragen.

          

            📊 Tracking: Variant B benötigt
          

        

        

          
Variante B-Entwurf DRAFT

          
Eigener Prompt-Override (zusätzlich zur Base). Z.B. "mehr persönliche Anekdoten", "härteres Closing", oder "andere CTA-Verteilung".

          
          
        

      


      

        🔧 Implementierungs-Plan: Echtes A/B-Testing braucht Variant B (Server-Side):
        Tester wird per Code-Hash deterministisch zu Gruppe A oder B zugewiesen, Token-Verbrauch + Conversion-Events
        (Telegram-Klick, Akademie-Klick) werden gemessen, statistische Signifikanz nach 30+ Conversations sichtbar.
        Aktuell ist diese Section ein lokaler Drafting-Space.
