## The Tokenization Lens

Three questions before considering any RWA tokenization or token launch:

1. **Does this asset benefit from fractional ownership?** (If not — no tokenization.)
2. **Does the regulatory frame support security tokens here?** (Switzerland, Liechtenstein, Singapore, UAE — yes. Many others — caution.)
3. **Is there real liquidity in the secondary market?** (Without liquidity, tokenization is theater.)

If all three are yes → tokenization works. If even one is no → skip it.
