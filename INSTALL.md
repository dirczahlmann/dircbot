## 🚀 Upload (1 Min)

1. ZIP entpacken
2. **github.com/dirczahlmann/dircbot** → **Add file** → **Upload files**
3. Drag den Ordner-Inhalt rein
4. Bei Duplikaten: **Replace existing file**
5. Commit: `Make portrait visible in hero background`
6. **Cmd+Shift+R**
